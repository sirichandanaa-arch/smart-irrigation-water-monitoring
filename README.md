# 🌱 AI-Assisted Irrigation Water Contamination Detection

## 📌 Overview

This project presents an AI-assisted smart irrigation water monitoring and contamination detection system designed for sustainable agriculture. The system continuously monitors irrigation water quality using IoT sensors and automatically controls water flow based on contamination levels.

The project helps farmers prevent crop damage, improve water management, and ensure that only safe water reaches agricultural fields.

---

## 🚀 Features

* Real-time water quality monitoring
* AI-assisted water contamination classification
* IoT-enabled smart irrigation system
* Automatic water diversion and flow control
* Multi-level contamination detection
* Remote monitoring dashboard
* Visual and buzzer alert system
* Low-cost and scalable solution for rural agriculture

---

## 🧠 Problem Statement

Farmers often use irrigation water without knowing whether it is contaminated or safe. Traditional methods rely on manual inspection and delayed laboratory testing, which can result in:

* Crop damage
* Reduced yield
* Soil degradation
* Water wastage
* Unsafe agricultural produce

This project provides a real-time automated solution to address these challenges.

---

## 💡 Proposed Solution

The system uses sensors to monitor:

* pH
* Turbidity
* TDS (Total Dissolved Solids)

An ESP32 microcontroller processes sensor data and classifies water into different contamination levels. Based on the classification:

* Safe water is supplied to crops
* Contaminated water is diverted automatically

The system also provides alerts and dashboard-based monitoring.

## ⚙️ System Workflow

1. Water enters through irrigation source
2. Sensors continuously monitor water quality
3. ESP32 processes sensor readings
4. Water is classified into contamination levels
5. Relay and solenoid valve control water flow
6. Safe water goes to crops
7. Unsafe water is diverted
8. Alerts and dashboard updates are generated

---

## 📊 Water Classification Levels

| Level   | Condition               | Action             |
| ------- | ----------------------- | ------------------ |
| Level 1 | Clear Water             | Allowed to crops   |
| Level 2 | Slightly Contaminated   | Monitoring enabled |
| Level 3 | Moderately Contaminated | Diverted           |
| Level 4 | Highly Contaminated     | Flow blocked       |
